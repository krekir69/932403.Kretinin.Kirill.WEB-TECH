Лабораторная работа №2. Базовые и продвинутые возможности CSS 
Цель: Научиться подключать стили, работать с селекторами, типографикой, цветами, 
отступами, позиционированием и псевдоклассами. 
Задание: 
Оформить страницу из ЛР №1 с помощью внешнего CSS файла (style.css).
Реализовать: 
1) Основной стиль – во внешнем файле; 1 элемент с inline стилями; 1 правило во 
внутреннем блоке <style>. 
2) CSS переменные в :root для цветов и шрифтов. 
3) Примеры позиционирования: static, relative, absolute. 
4) Состояния элементов: :hover, :active, :focus, :visited. 
5) Контрастность текста не менее 4.5:1.
 
Вариант 8. Тема «Кулинар и фуд-блогер» (эффект «аппетитного» hover)  
Карточки проектов сделайте с закруглёнными углами и эффектом «размытия фона» при 
наведении (через filter: blur() на псевдоэлементе). При :focus на полях формы добавляйте 
тонкую жёлтую обводку. В переменных: основной – кремовый, акцент – терракотовый. 
Inline-стиль: object-fit: cover для изображения. Внутренний блок: стили для заголовков <h2>
